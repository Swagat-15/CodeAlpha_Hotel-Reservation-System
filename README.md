# Hotel Reservation System

## Overview
The **Hotel Reservation System** is a Java-based console application developed using **Object-Oriented Programming (OOP)** principles and **JDBC with MySQL** for database management. The project simulates a real-world hotel booking system where users can search available rooms, make reservations, manage bookings, process payments, and maintain room availability.
This project demonstrates the practical implementation of Java, JDBC connectivity, SQL operations, exception handling, and database-driven application development.

## Features
* View all available hotel rooms
* Search rooms by category (Standard, Deluxe, Suite)
* Book hotel rooms
* View all reservations
* View booking details
* Update reservation information
* Cancel reservations
* Automatic room availability management
* Payment simulation (Cash, Card, UPI)
* View payment history
* MySQL database integration using JDBC
* Modular Object-Oriented Programming (OOP) design
